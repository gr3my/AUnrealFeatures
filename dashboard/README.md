# Ares Dashboard

Operator UI for the Ares read/write APIs.

## Local development

1. Copy `.env.example` to your preferred local environment configuration.
2. Set the backend URLs for your deployment.
3. Install dependencies with `npm install`.
4. Start the dashboard with `npm run dev`.

The default configuration targets local backend services only. Do not expose an unauthenticated operator dashboard directly to the public internet.
